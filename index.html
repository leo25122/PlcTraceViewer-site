Registrazione e analisi di segnali · PLC S7 Signal recording and analysis · S7 PLCs

Registra e analizza i segnali dei PLC S7.

Record and analyse signals from S7 PLCs.

PlcTraceViewer si collega alla CPU con la linea in produzione, legge i segnali che scegli e li salva su disco con l'ora esatta di ogni lettura. L'acquisizione gira in un processo separato dall'interfaccia, quindi l'uso della finestra non influisce sui tempi di campionamento.

PlcTraceViewer connects to the CPU while the line is in production, reads the signals you select and saves them to disk with the exact time of each read. Acquisition runs in a process separate from the user interface, so using the window does not affect sampling times.

Acquisizione separata dall'interfaccia.

Acquisition kept separate from the user interface.

Quando l'acquisizione gira nello stesso processo della finestra, basta scorrere un elenco o ridisegnare un grafico perché una lettura parta in ritardo. In PlcTraceViewer l'acquisizione gira in un processo separato ad alta priorità che non disegna nulla: legge il PLC e assegna a ogni campione l'istante in cui è arrivata la risposta.

When acquisition runs in the same process as the window, scrolling a list or redrawing a chart is enough to delay a read. In PlcTraceViewer acquisition runs in a separate high-priority process that draws nothing: it reads the PLC and gives each sample the time at which the answer arrived.

Nomi dei segnali

Signal names

I segnali mantengono i nomi del progetto TIA. I nomi si possono prendere dal progetto (.ap16 → .ap21), dalle sorgenti dei blocchi (.db, .scl, .udt), da una tabella dei tag (.xlsx, .csv) oppure leggere direttamente dalla CPU, anche senza il progetto.

Signals keep the names from the TIA project. Names can come from the project (.ap16 → .ap21), from block sources (.db, .scl, .udt), from a tag table (.xlsx, .csv), or be read directly from the CPU, even without the project.

Blocchi ottimizzati.Optimised blocks. Non hanno indirizzi assoluti, quindi si leggono solo con OPC UA o S7comm-Plus. Il programma lo riconosce e lo segnala, invece di restituire zeri. They have no absolute addresses, so they can only be read with OPC UA or S7comm-Plus. The program detects this and reports it instead of returning zeros.

Quando la rete non bastaWhen the network is not enough

Campionamento a 1 ms dentro la CPU.

1 ms sampling inside the CPU.

Se l'intervallo necessario non è raggiungibile in rete, il programma genera i blocchi da importare in TIA: il PLC campiona al ritmo del proprio OB e l'applicazione legge i dati a blocchi. Il periodo dei campioni non dipende più dal traffico di rete.

If the interval you need cannot be reached over the network, the program generates blocks to import into TIA: the PLC samples at the rate of its own OB and the application reads the data in batches. The sample period no longer depends on network traffic.

Si sceglie quanti segnali per tipo e la profondità del buffer; la memoria occupata nel PLC viene indicata prima della generazione. I blocchi sono nuovi e quelli esistenti non vengono modificati.

You choose how many signals of each type and the buffer depth; the memory used in the PLC is shown before generating. The blocks are new and existing ones are not modified.

LimitiLimitations

Cosa non fa

What it does not do

Meglio saperlo prima di portarlo in impianto.

Worth knowing before you take it to a plant.

  • Non scrive nel PLC. Legge soltanto: non forza variabili, non modifica il programma e non cambia lo stato della CPU.
  • Non garantisce un intervallo fisso. L'intervallo raggiungibile dipende da CPU, canali e rete: viene misurato in impianto e indicato.
  • Non legge i blocchi ottimizzati tramite indirizzo. Questi blocchi non hanno indirizzi assoluti; servono OPC UA o S7comm-Plus.
  • Non è un ambiente di programmazione. Non modifica né compila progetti PLC e non fa diagnostica hardware.
  • Non è un sistema di archiviazione storica. È uno strumento per la messa in servizio e la ricerca guasti, non un archivio permanente dei dati di processo.
  • Senza licenza non registra. La versione Free apre e analizza le registrazioni; collegamento al PLC, registrazione ed esportazioni richiedono la licenza PRO.
  • Non richiede internet. Né per l'uso né per attivare la licenza. Se una connessione è disponibile, il programma verifica lo stato della licenza sul portale senza inviare dati d'impianto.
  • It does not write to the PLC. It only reads: it does not force variables, change the program or change the CPU state.
  • It does not guarantee a fixed interval. The interval that can be reached depends on the CPU, the channels and the network: it is measured on site and shown.
  • It does not read optimised blocks by address. These blocks have no absolute addresses; OPC UA or S7comm-Plus is needed.
  • It is not a programming environment. It does not edit or compile PLC projects and does no hardware diagnostics.
  • It is not a historian. It is a tool for commissioning and fault finding, not a permanent archive of process data.
  • It does not record without a licence. The Free version opens and analyses recordings; connecting to the PLC, recording and exporting need a PRO licence.
  • It does not need internet. Neither for use nor for activating the licence. If a connection is available, the program checks the licence status on the portal without sending plant data.

No, né per l'uso né per attivare la licenza. Se una connessione è disponibile, il programma verifica lo stato della licenza sul portale senza inviare dati d'impianto. Non ci sono servizi cloud né accessi remoti dall'esterno della rete di impianto. No, neither for use nor for activating the licence. If a connection is available, the program checks the licence status on the portal without sending plant data. There are no cloud services and no remote access from outside the plant network.
Che file produce e come si leggono?What files does it produce and how are they read?
Un formato binario proprietario (.drug), compresso automaticamente alla chiusura del file (.drug.gz) e organizzato in una cartella per giorno. A proprietary binary format (.drug), compressed automatically when the file is closed (.drug.gz) and organised in one folder per day. Posso lasciarlo registrare tutta la notte?Can I leave it recording all night?
Sì. I file ruotano per dimensione; i più vecchi vengono compressi e poi eliminati secondo il periodo di conservazione impostato, senza toccare la registrazione in corso. La scrittura è controllata: se si interrompe, viene segnalato. Yes. Files rotate by size; the oldest are compressed and then deleted according to the retention period you set, without touching the recording in progress. Writing is monitored: if it stops, this is reported.

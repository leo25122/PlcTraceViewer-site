Registra e analizza i segnali dei PLC S7

Record and analyse signals from S7 PLCs

PlcTraceViewer si collega alla CPU con la linea in produzione, legge i segnali che scegli e li salva su disco con l'ora esatta di ogni lettura. L'acquisizione gira in un processo separato dall'interfaccia, quindi l'uso della finestra non influisce sui tempi di campionamento.

PlcTraceViewer connects to the CPU while the line is in production, reads the signals you select and saves them to disk with the exact time of each read. Acquisition runs in a process separate from the user interface, so using the window does not affect sampling times.

01

Per capire un fermo servono i segnali dei secondi precedenti

To understand a stop you need the signals from the seconds before it

Servono i valori di quei secondi, ognuno con il suo tempo. Gli strumenti che di solito si hanno a disposizione non bastano.

You need the values of those seconds, each with its own time. The tools usually at hand are not enough.

Il trace della CPU è limitato

The CPU trace is limited

Buffer piccolo, pochi segnali e si ferma quando è pieno. Un guasto che si presenta di rado può non essere catturato.

A small buffer, few signals, and it stops when it is full. A fault that appears rarely may never be captured.

L'HMI mostra il presente

The HMI shows the present

Serve per condurre l'impianto, non per ricostruire un evento di 40 ms avvenuto ore prima.

It is made for running the plant, not for reconstructing a 40 ms event that happened hours ago.

Un export senza tempi non basta

An export without timestamps is not enough

Senza l'istante di ogni lettura non si può misurare un ritardo né confrontare due segnali.

Without the time of each read you cannot measure a delay or compare two signals.

Ti colleghi, scegli i canali e registri

Connect, choose the channels and record

Non serve preparare un progetto né caricare blocchi nella CPU: si può registrare pochi minuti dopo l'installazione.

There is no project to prepare and nothing to load into the CPU: you can record a few minutes after installing.

    Signals with their TIA names

    Before opening the file, the program checks that the CPU can answer at the requested interval. If it cannot, it says so and suggests a longer interval.

04

Acquisizione separata dall'interfaccia

Acquisition kept separate from the user interface

Quando l'acquisizione gira nello stesso processo della finestra, basta scorrere un elenco o ridisegnare un grafico perché una lettura parta in ritardo. In PlcTraceViewer l'acquisizione gira in un processo separato ad alta priorità che non disegna nulla: legge il PLC e assegna a ogni campione l'istante in cui è arrivata la risposta.

When acquisition runs in the same process as the window, scrolling a list or redrawing a chart is enough to delay a read. In PlcTraceViewer acquisition runs in a separate high-priority process that draws nothing: it reads the PLC and gives each sample the time at which the answer arrived.

05

Cosa garantisce la registrazione

What the recording guarantees

Spesso una registrazione inutilizzabile si scopre solo quando l'impianto è già ripartito. Per questo il programma controlla il file mentre lo scrive.

An unusable recording is often discovered only after the plant has restarted. That is why the program checks the file while writing it.

  • Tempi reali

    Real timestamps

    Ogni campione riporta l'istante in cui è stato letto, preso dal processo di acquisizione e non dall'interfaccia.

    Each sample carries the time it was read, taken by the acquisition process and not by the user interface.

  • Nessun valore inventato

    No invented values

    Un valore non letto resta un valore mancante e compare come tale nell'analisi. Non viene sostituito con zero, che sembrerebbe una misura vera.

    A value that was not read stays missing and appears as such in the analysis. It is not replaced with zero, which would look like a real measurement.

  • Verifica prima di registrare

    Checked before recording

    L'intervallo richiesto viene provato sulla CPU prima di aprire il primo file. Se non è raggiungibile, il programma propone quello che la CPU riesce a mantenere.

    The requested interval is tested on the CPU before the first file is opened. If it cannot be reached, the program suggests the one the CPU can sustain.

  • Scrittura controllata

    Monitored writing

    La scrittura su disco è controllata per tutta la durata della registrazione e lo spazio su disco è gestito automaticamente. Se la scrittura si interrompe, il programma lo segnala subito.

    Writing to disk is monitored for the whole recording and disk space is managed automatically. If writing stops, the program reports it immediately.

Campionamento a 1 ms dentro la CPU

1 ms sampling inside the CPU

Se l'intervallo necessario non è raggiungibile in rete, il programma genera i blocchi da importare in TIA: il PLC campiona al ritmo del proprio OB e l'applicazione legge i dati a blocchi. Il periodo dei campioni non dipende più dal traffico di rete.

If the interval you need cannot be reached over the network, the program generates blocks to import into TIA: the PLC samples at the rate of its own OB and the application reads the data in batches. The sample period no longer depends on network traffic.

Si sceglie quanti segnali per tipo e la profondità del buffer; la memoria occupata nel PLC viene indicata prima della generazione. I blocchi sono nuovi e quelli esistenti non vengono modificati.

You choose how many signals of each type and the buffer depth; the memory used in the PLC is shown before generating. The blocks are new and existing ones are not modified.

A Windows service publishes a page that any PC on the plant network can open: live values, recent trend, disk status, start and stop of the recording.

La registrazione avviata dalla pagina è la stessa dell'applicazione, non una copia separata: un solo registratore e un solo file.

The recording started from the page is the application's own, not a separate copy: one recorder and one file.

Cosa non fa

What it does not do

Meglio saperlo prima di portarlo in impianto.

Worth knowing before you take it to a plant.

  • Non scrive nel PLC

    Legge soltanto: non forza variabili, non modifica il programma e non cambia lo stato della CPU.

  • Non garantisce un intervallo fisso

    L'intervallo raggiungibile dipende da CPU, canali e rete: viene misurato in impianto e indicato.

  • Non legge i blocchi ottimizzati tramite indirizzo

    Questi blocchi non hanno indirizzi assoluti; servono OPC UA o S7comm-Plus.

  • Non è un ambiente di programmazione

    Non modifica né compila progetti PLC e non fa diagnostica hardware.

  • Non è un sistema di archiviazione storica

    È uno strumento per la messa in servizio e la ricerca guasti, non un archivio permanente dei dati di processo.

  • Senza licenza non registra

    La versione Free apre e analizza le registrazioni; collegamento al PLC, registrazione ed esportazioni richiedono la licenza PRO.

  • Non richiede internet

    Né per l'uso né per attivare la licenza. Se una connessione è disponibile, il programma verifica lo stato della licenza sul portale senza inviare dati d'impianto.

  • It does not write to the PLC

    It only reads: it does not force variables, change the program or change the CPU state.

  • It does not guarantee a fixed interval

    The interval that can be reached depends on the CPU, the channels and the network: it is measured on site and shown.

  • It does not read optimised blocks by address

    These blocks have no absolute addresses; OPC UA or S7comm-Plus is needed.

  • It is not a programming environment

    It does not edit or compile PLC projects and does no hardware diagnostics.

  • It is not a historian

    It is a tool for commissioning and fault finding, not a permanent archive of process data.

  • It does not record without a licence

    The Free version opens and analyses recordings; connecting to the PLC, recording and exporting need a PRO licence.

  • It does not need internet

    Neither for use nor for activating the licence. If a connection is available, the program checks the licence status on the portal without sending plant data.

Sì. I file ruotano per dimensione; i più vecchi vengono compressi e poi eliminati secondo il periodo di conservazione impostato, senza toccare la registrazione in corso. La scrittura è controllata: se si interrompe, viene segnalato. Yes. Files rotate by size; the oldest are compressed and then deleted according to the retention period you set, without touching the recording in progress. Writing is monitored: if it stops, this is reported.

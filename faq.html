A · Prima di acquistareA · Before you buy

Il programma scrive nel PLC? Che cosa posso fare con la versione FREE?Does the program write to the PLC? What can I do with the FREE version?
La risposta sulla sola lettura e sulle funzioni FREE/PRO è già nella FAQ generale della pagina principale.The answers about read-only operation and the FREE/PRO feature split are already in the main-page FAQ.
Quali connessioni sono supportate e che cosa va abilitato sulla CPU?Which connections are supported, and what must be enabled on the CPU?
  • PUT/GET — S7-300/400/1200/1500, lettura per indirizzo. Consenti l'accesso PUT/GET nella configurazione della CPU. I DB a accesso ottimizzato non sono leggibili con questo metodo.
  • S7comm-Plus — S7-1500 da V2.9 e S7-1200 da V4.3, accesso simbolico. Abilita la comunicazione sicura PG/PC e HMI. Non serve una licenza runtime OPC UA.
  • OPC UA — S7-1200/1500, accesso simbolico. Il server OPC UA deve essere attivo e avere la licenza runtime prevista per la CPU: licenza e configurazione del PLC sono a carico del cliente.
  • PUT/GET — S7-300/400/1200/1500, by-address reads. Allow PUT/GET access in the CPU configuration. Optimised-access DBs cannot be read this way.
  • S7comm-Plus — S7-1500 V2.9 and later, and S7-1200 V4.3 and later, with symbolic access. Enable secure PG/PC and HMI communication. No OPC UA runtime licence is needed.
  • OPC UA — S7-1200/1500, with symbolic access. The OPC UA server must be enabled and have the runtime licence required by the CPU; the customer provides the PLC licence and configuration.
Quali requisiti servono sul PC per TIA e per i PDF?What PC requirements apply to TIA and PDF files?
  • Windows 10/11 a 64 bit. Il runtime dell'applicazione è incluso nell'installer.
  • .NET Framework 4.8 serve solo al modulo opzionale che legge un progetto TIA; è già incluso in Windows 10 versione 1903 o successiva e in Windows 11.
  • Per importare un progetto servono TIA Portal con Openness installato e licenziato dal cliente e l'utente Windows nel gruppo locale Siemens TIA Openness. TIA/Openness non sono inclusi in PlcTraceViewer e non servono per acquisire dal PLC.
  • Per leggere il manuale o l'EULA in PDF serve un lettore PDF.
  • 64-bit Windows 10 or 11. The application runtime is included in the installer.
  • .NET Framework 4.8 is needed only by the optional module that reads a TIA project; it is already included in Windows 10 version 1903 or later and Windows 11.
  • Importing a project requires TIA Portal with Openness installed and licensed by the customer, and the Windows user must belong to the local Siemens TIA Openness group. TIA/Openness is not included with PlcTraceViewer and is not needed to acquire from a PLC.
  • A PDF reader is needed to open the PDF manual or EULA.
Quali dati escono dal PC?What data leaves the PC?
I valori del PLC, i nomi dei segnali e i file di registrazione restano sul PC: non vengono caricati su un servizio cloud. L'attivazione è offline. Se è disponibile una connessione, il controllo dello stato della licenza usa il seriale della licenza e il codice macchina; non invia dati d'impianto. Per il funzionamento senza internet, vedi anche la risposta generale.PLC values, signal names and recording files stay on the PC; they are not uploaded to a cloud service. Activation is offline. If a connection is available, the licence-status check uses the licence serial and Machine Code; it does not send plant data. For use without internet, also see the general answer.

B · Richiedere la licenzaB · Request a licence

Che cos'è il codice macchina e dove lo trovo?What is the Machine Code, and where do I find it?
È il codice associato al PC per cui viene emessa la licenza. In PlcTraceViewer apri ? → Activate PRO e copialo dalla finestra, mantenendo i trattini. Se reinstalli Windows il codice può cambiare.It identifies the PC for which a licence is issued. In PlcTraceViewer open ? → Activate PRO and copy it from that window, including the dashes. Reinstalling Windows can change the code.
Come invio una richiesta?How do I submit a request?
  1. Apri il portale licenze.
  2. Inserisci il codice macchina, nome, azienda ed e-mail; telefono e note sono facoltativi.
  3. Invia una sola richiesta per codice macchina e conserva nome ed e-mail inseriti: serviranno per controllarne lo stato.
  4. Quando il portale rende disponibile la licenza, scarica il file .ptvlic dalla pagina dello stato.
  1. Open the licence portal.
  2. Enter the Machine Code, name, company and email; phone and notes are optional.
  3. Submit one request per machine code and keep the name and email you entered; they are needed to check its status.
  4. When the portal makes the licence available, download the .ptvlic file from the status page.
Che cosa significa «troppe richieste»?What does “too many requests” mean?
Il portale limita l'invio: al massimo 30 richieste in attesa, 20 richieste complessive nelle ultime 24 ore e 3 richieste per e-mail nelle ultime 24 ore. Una richiesta già in attesa per lo stesso codice macchina non va inviata di nuovo: controllane lo stato. Se appare l'avviso di limite, riprova più tardi.The portal limits submissions: at most 30 requests awaiting review, 20 requests overall in the last 24 hours and 3 requests per email in the last 24 hours. Do not submit another request for a machine code that is already awaiting review; check its status instead. If the limit message appears, try again later.
Come controllo lo stato e quali file ricevo?How do I check the status, and which files will I receive?
Apri Stato della richiesta e inserisci codice macchina, nome completo ed e-mail usati nella richiesta. Da lì puoi vedere lo stato e, quando disponibile, scaricare la licenza .ptvlic e il certificato PDF. Il periodo di una licenza a termine inizia al primo download; scaricarla di nuovo non lo azzera.Open Request status and enter the Machine Code, full name and email used in the request. You can see the status and, when available, download the .ptvlic licence and certificate PDF. A time-limited licence starts on its first download; downloading it again does not restart the term.

C · AttivareC · Activate

Come importo il file .ptvlic?How do I import the .ptvlic file?
  1. Apri ? → Activate PRO (oppure fai clic sul badge FREE).
  2. Scegli Import licence file e seleziona il file scaricato dal portale.
  3. Alla conferma, la licenza viene salvata nell'app. Il file importato può essere rimosso automaticamente; se il portale lo rende ancora disponibile, puoi scaricarlo di nuovo.
  1. Open ? → Activate PRO (or click the FREE badge).
  2. Choose Import licence file and select the file downloaded from the portal.
  3. When the import succeeds, the licence is saved in the app. The imported file may be removed automatically; if the portal still offers it, you can download it again.
Posso incollare una chiave invece di importare il file?Can I paste a key instead of importing the file?
Sì. Nella finestra Activate PRO apri l'opzione per inserire la chiave, incolla il testo ricevuto e scegli Activate. L'importazione del file .ptvlic è il metodo principale.Yes. In Activate PRO, open the key-entry option, paste the text you received and choose Activate. Importing the .ptvlic file is the primary method.
Che cosa faccio se l'attivazione mostra un errore?What should I do if activation shows an error?
  • This licence belongs to another machine.: controlla che il codice macchina sia quello del PC attuale; chiedi dal portale una licenza per quel codice.
  • The licence is not valid for this machine.: verifica di aver ricevuto il file per il codice macchina corretto; se il messaggio resta, contatta il fornitore tramite il portale.
  • The licence expired on …: controlla la data mostrata e invia una nuova richiesta dal portale.
  • The … recording hours of this licence are used up …: la quota è terminata; contatta il fornitore tramite il portale.
  • Licence … has been withdrawn.: le funzioni PRO sono disattivate; chiedi informazioni al fornitore tramite il portale.
  • The date on this PC (…) is earlier than the date this licence was issued (…).: imposta la data corretta e riavvia l'app; non è un blocco permanente. Per il messaggio Licence … was locked on this PC because the clock was set back., correggi la data e chiedi una nuova licenza per lo stesso codice macchina tramite il portale: reinstallare non sblocca la licenza.
  • This licence belongs to another machine.: check that the Machine Code is for this PC; request a licence for that code through the portal.
  • The licence is not valid for this machine.: check that the file was issued for the correct Machine Code; if the message remains, contact the supplier through the portal.
  • The licence expired on …: check the date shown and submit a new request through the portal.
  • The … recording hours of this licence are used up …: the quota has ended; contact the supplier through the portal.
  • Licence … has been withdrawn.: PRO features are disabled; ask the supplier for information through the portal.
  • The date on this PC (…) is earlier than the date this licence was issued (…).: set the correct date and restart the app; this is not a permanent lock. For Licence … was locked on this PC because the clock was set back., correct the date and request a new licence for the same Machine Code through the portal; reinstalling will not unlock it.

D · Durante l'usoD · While using it

Quali tipi di licenza esistono?Which licence types are available?
In base al file emesso, una licenza può essere perpetua o avere una data di scadenza; può inoltre includere una quota di ore di registrazione e/o un limite ai tag Live. Il portale mostra la scadenza e i limiti assegnati. Non sono indicate qui tariffe o condizioni commerciali.Depending on the licence issued, it may be perpetual or have an expiry date; it may also include a recording-hour quota and/or a limit on Live tags. The portal shows the expiry and assigned limits. Prices and commercial terms are not stated here.
Che cosa succede quando scade o finisce una quota?What happens when a term or quota ends?
Quando scade la licenza o si esauriscono le ore, le funzioni PRO terminano. Se REC è già in corso, non viene interrotta: il file viene chiuso integro e le funzioni PRO si disattivano quando fermi la registrazione. Se raggiungi il limite dei tag Live, non puoi aggiungerne altri finché non ne rimuovi uno.When the licence expires or its hour quota runs out, PRO features end. If REC is already running, it is not interrupted: the file is closed intact and PRO features are disabled when you stop recording. If you reach the Live-tag limit, remove a tag before adding another.
Se aggiorno l'app, la licenza resta valida?Does my licence remain valid when I update the app?
Un aggiornamento compatibile sullo stesso PC non cambia il codice macchina. Le licenze emesse per versioni precedenti non sono accettate da questa versione: copia il codice macchina e chiedi al fornitore una licenza sostitutiva tramite il portale.A compatible update on the same PC does not change its Machine Code. Licences issued for earlier versions are not accepted by this version: copy the Machine Code and ask the supplier for a replacement licence through the portal.
Che cosa succede se reinstallo Windows o cambio PC?What happens if I reinstall Windows or change PC?
Il codice macchina può cambiare: la licenza è associata al codice del PC precedente. Invia una nuova richiesta dal portale indicando il nuovo codice e chiedi il trasferimento. La licenza precedente viene disattivata quando il trasferimento è completato. Sostituire un disco o aggiungere memoria, da soli, non cambia il codice macchina.The Machine Code can change: the licence is tied to the previous PC's code. Submit a new request through the portal with the new code and ask for a transfer. The previous licence is disabled when the transfer is completed. Replacing a disk or adding memory alone does not change the Machine Code.
Il PC si è guastato o ho perso il file della licenza: come procedo?The PC failed or I lost the licence file. What should I do?
Per un file perso, controlla lo stato della richiesta sul portale: una licenza attiva può essere scaricata di nuovo. Se il PC non è più utilizzabile o il codice macchina è cambiato, contatta il fornitore tramite il portale con il seriale e il nuovo codice, se disponibili; sarà valutata l'emissione o il trasferimento.If the file was lost, check the request status on the portal: an active licence can be downloaded again. If the PC can no longer be used or its Machine Code changed, contact the supplier through the portal with the serial and new code, if available; the supplier will assess a reissue or transfer.

E · Data e oraE · Date and time

Posso riportare indietro l'orologio del PC?Can I set the PC clock back?
No. Riportare indietro l'orologio può bloccare permanentemente una licenza a scadenza su quel PC. Se è successo, correggi la data e chiedi tramite il portale una nuova licenza per lo stesso codice macchina. Reinstallare l'app non risolve il blocco. Le licenze perpetue non hanno una scadenza da verificare.No. Setting the clock back can permanently lock a time-limited licence on that PC. If this happened, correct the date and request a new licence for the same Machine Code through the portal. Reinstalling the app does not clear the lock. Perpetual licences have no expiry to check.
Fuso orario o ora legale possono bloccare la licenza?Can a time zone or daylight-saving change lock the licence?
No: cambiare fuso orario o passare all'ora legale non equivale a riportare indietro la data del PC. Non modificare manualmente la data per simulare un altro fuso.No: changing the time zone or switching to daylight-saving time is not the same as setting the PC date back. Do not change the date manually to simulate another time zone.
La batteria scarica del BIOS ha impostato una data precedente: che faccio?A flat BIOS battery set an earlier date. What should I do?
Imposta la data e l'ora corrette di Windows. Una data precedente al giorno di emissione della licenza va corretta; da sola non comporta il blocco permanente descritto sopra. Anche una licenza appena importata non viene bloccata per una data errata precedente alla sua importazione.Set the correct Windows date and time. A date earlier than the licence issue date must be corrected; on its own, it does not cause the permanent lock described above. A newly imported licence is not locked because of an incorrect date that predates its import.

F · Revoca e trasferimentoF · Withdrawal and transfer

Che cosa succede se una licenza viene ritirata?What happens if a licence is withdrawn?
La finestra passa alla versione FREE e le funzioni PRO vengono disattivate; l'app mostra un avviso. Per sapere il motivo o richiedere una nuova licenza, contatta il fornitore tramite il portale. In caso di trasferimento a un altro PC, la licenza precedente viene sostituita.The app switches to FREE and PRO features are disabled; a message is shown. Contact the supplier through the portal to ask why or request a new licence. When a licence is transferred to another PC, the previous one is superseded.
Il PC è offline: la licenza smette di funzionare?The PC is offline. Will the licence stop working?
No. L'assenza di rete non impedisce l'attivazione o il normale uso offline. Un PC offline non può ricevere in quel momento un aggiornamento dello stato della licenza dal portale; la revoca può arrivare quando il PC torna online o installa una versione successiva dell'app. Non vengono trasferiti dati del PLC.No. Being offline does not prevent activation or normal offline use. An offline PC cannot receive a licence-status update from the portal at that time; a withdrawal may be received when it reconnects or installs a later app version. No PLC data is transferred.

G · InstallazioneG · Installation

Windows SmartScreen mostra un avviso: come procedo?Windows SmartScreen shows a warning. What should I do?
Prima verifica che il file provenga dalla pagina ufficiale delle release. Per proseguire con l'installer, seleziona Ulteriori informazioni → Esegui comunque.First check that the file came from the official releases page. To continue with the installer, select More info → Run anyway.
L'installazione è per utente? Serve installare .NET?Is installation per-user? Do I need to install .NET?
L'installer consente l'installazione per utente e include il runtime dell'app: non occorre procurarsi .NET separatamente. Per aggiornare, chiudi prima PlcTraceViewer e avvia l'installer sopra la versione esistente.The installer supports per-user installation and includes the application runtime; there is no need to obtain .NET separately. To update, close PlcTraceViewer first and run the installer over the existing version.
Che cos'è il servizio web e quando serve?What is the web service, and when do I need it?
È il componente opzionale per la dashboard Live nel browser sulla rete locale, predefinita sulla porta 8085. La dashboard è una funzione PRO e non ha autenticazione: usala solo su una rete attendibile. Installare il servizio richiede il consenso di Windows; se non vuoi la dashboard, non selezionare il relativo componente durante l'installazione.It is the optional component for the Live browser dashboard on the local network, using port 8085 by default. The dashboard is a PRO feature and has no authentication: use it only on a trusted network. Installing the service requires Windows permission; if you do not need the dashboard, leave that component unselected during setup.
Come disinstallo il programma e il servizio?How do I uninstall the program and service?
Usa la voce di disinstallazione di PlcTraceViewer dal menu Start o da Impostazioni Windows → App installate. La procedura gestisce il servizio web prima di rimuovere i file; Windows può chiedere il permesso per fermarlo o rimuoverlo.Use the PlcTraceViewer uninstall entry in the Start menu or in Windows Settings → Installed apps. Setup handles the web service before removing files; Windows may ask permission to stop or remove it.
L'antivirus blocca l'app o la connessione: che cosa faccio?My antivirus blocks the app or connection. What should I do?
Verifica che l'installer provenga dalla pagina ufficiale delle release e segui la procedura IT della tua organizzazione per esaminare l'avviso. Se il blocco riguarda la dashboard web, controlla anche il servizio e la porta 8085.Verify that the installer came from the official releases page and follow your organisation's IT process to review the alert. If the block affects the web dashboard, also check the service and port 8085.

I · SupportoI · Support

Quando contatto il supporto e quali informazioni invio?When should I contact support, and what information should I send?
Contatta il supporto se il portale non riconosce una richiesta, l'attivazione fallisce dopo aver verificato il codice macchina o compare un errore non spiegato qui. Per una richiesta di licenza invia tramite il portale licenze il seriale, il codice macchina, la versione di PlcTraceViewer e il testo esatto del messaggio. Per un problema tecnico usa Segnala un problema e indica versione e messaggio, senza seriale né codice macchina. Non allegare registrazioni o dati d'impianto a una segnalazione pubblica.Contact support if the portal cannot find a request, activation still fails after checking the Machine Code, or an error appears that is not covered here. For a licence request, use the licence portal and include the serial, Machine Code, PlcTraceViewer version and exact message. For a technical issue, use Report an issue and include the version and message, but not the serial or Machine Code. Do not attach recordings or plant data to a public report.

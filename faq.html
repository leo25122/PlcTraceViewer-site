A. Prima di acquistareA. Before you buy

Il programma scrive nel PLC? Cosa si può fare con la versione Free?Does the program write to the PLC? What can I do with the Free version?
Le risposte sulla sola lettura e sulle funzioni Free e PRO sono nelle domande generali della pagina principale.The answers about read-only operation and the Free and PRO features are in the general questions on the main page.
Quali collegamenti sono supportati e cosa va abilitato sulla CPU?Which connections are supported and what must be enabled on the CPU?
  • PUT/GET: S7-300/400/1200/1500, lettura per indirizzo. Va consentito l'accesso PUT/GET nella configurazione della CPU. I DB ad accesso ottimizzato non si possono leggere in questo modo.
  • S7comm-Plus: S7-1500 dalla V2.9 e S7-1200 dalla V4.3, lettura per nome. Va abilitata la comunicazione sicura PG/PC e HMI. Non serve una licenza runtime OPC UA.
  • OPC UA: S7-1200/1500, lettura per nome. Il server OPC UA deve essere attivo e avere la licenza runtime prevista per la CPU; licenza e configurazione del PLC sono a carico del cliente.
  • PUT/GET: S7-300/400/1200/1500, reading by address. PUT/GET access must be allowed in the CPU configuration. DBs with optimised access cannot be read this way.
  • S7comm-Plus: S7-1500 from V2.9 and S7-1200 from V4.3, reading by name. Secure PG/PC and HMI communication must be enabled. No OPC UA runtime licence is needed.
  • OPC UA: S7-1200/1500, reading by name. The OPC UA server must be enabled and have the runtime licence required for the CPU; the PLC licence and configuration are the customer's responsibility.
Quali sono i requisiti del PC?What are the PC requirements?
  • Windows 10 o 11 a 64 bit. Il runtime dell'applicazione è incluso nell'installazione.
  • .NET Framework 4.8 serve solo al modulo facoltativo che legge i progetti TIA; è già presente in Windows 10 dalla versione 1903 e in Windows 11.
  • Per leggere un progetto servono TIA Portal con Openness, installato e con licenza del cliente, e l'utente Windows nel gruppo locale Siemens TIA Openness. TIA Portal e Openness non sono inclusi in PlcTraceViewer e non servono per acquisire dal PLC.
  • Per aprire il manuale o l'EULA in PDF serve un lettore PDF.
  • 64-bit Windows 10 or 11. The application runtime is included in the installer.
  • .NET Framework 4.8 is needed only by the optional module that reads TIA projects; it is already part of Windows 10 from version 1903 and of Windows 11.
  • Reading a project requires TIA Portal with Openness, installed and licensed by the customer, and the Windows user in the local Siemens TIA Openness group. TIA Portal and Openness are not included in PlcTraceViewer and are not needed to acquire from the PLC.
  • A PDF reader is needed to open the PDF manual or the EULA.
Quali dati escono dal PC?What data leaves the PC?
I valori del PLC, i nomi dei segnali e i file di registrazione restano sul PC e non vengono caricati su servizi cloud. L'attivazione non richiede internet. Se una connessione è disponibile, il controllo dello stato della licenza invia solo il seriale della licenza e il codice macchina, nessun dato d'impianto. Per l'uso senza internet vedi anche la risposta generale.PLC values, signal names and recording files stay on the PC and are not uploaded to cloud services. Activation does not need internet. If a connection is available, the licence-status check sends only the licence serial and the Machine Code, no plant data. For use without internet, see also the general answer.

B. Richiesta della licenzaB. Requesting a licence

Cos'è il codice macchina e dove si trova?What is the Machine Code and where do I find it?
È il codice che identifica il PC per cui viene emessa la licenza. In PlcTraceViewer apri ? → Activate PRO version e copialo dalla finestra, trattini compresi. Se reinstalli Windows il codice può cambiare.It is the code that identifies the PC the licence is issued for. In PlcTraceViewer open ? → Activate PRO version and copy it from the window, dashes included. Reinstalling Windows can change the code.
Come si invia una richiesta?How do I send a request?
  1. Apri il portale licenze.
  2. Inserisci codice macchina, nome, azienda ed e-mail; telefono e note sono facoltativi.
  3. Invia una sola richiesta per codice macchina e conserva il nome e l'e-mail usati: servono per controllarne lo stato.
  4. Quando la licenza è disponibile, scarica il file .ptvlic dalla pagina dello stato.
  1. Open the licence portal.
  2. Enter the Machine Code, name, company and email; phone and notes are optional.
  3. Send only one request per Machine Code and keep the name and email you used: they are needed to check its status.
  4. When the licence is available, download the .ptvlic file from the status page.
Cosa significa «troppe richieste»?What does “too many requests” mean?
Il portale limita gli invii: al massimo 30 richieste in attesa, 20 richieste in totale nelle ultime 24 ore e 3 richieste per indirizzo e-mail nelle ultime 24 ore. Se per lo stesso codice macchina c'è già una richiesta in attesa, non inviarne un'altra: controllane lo stato. Se compare l'avviso, riprova più tardi.The portal limits submissions: at most 30 requests awaiting review, 20 requests in total in the last 24 hours and 3 requests per email address in the last 24 hours. If a request for the same Machine Code is already waiting, do not send another one: check its status. If the message appears, try again later.
Come si controlla lo stato e quali file si ricevono?How do I check the status and which files do I receive?
Apri Stato della richiesta e inserisci codice macchina, nome completo ed e-mail usati nella richiesta. Qui vedi lo stato e, quando è disponibile, scarichi la licenza .ptvlic e il certificato in PDF. La durata di una licenza a tempo parte dal primo download; scaricarla di nuovo non la azzera.Open Request status and enter the Machine Code, full name and email used in the request. There you see the status and, when available, download the .ptvlic licence and the PDF certificate. The term of a time-limited licence starts at the first download; downloading it again does not reset it.

C. AttivazioneC. Activation

Come si importa il file .ptvlic?How do I import the .ptvlic file?
  1. Apri ? → Activate PRO version oppure fai clic sul riquadro FREE.
  2. Scegli Import licence file e seleziona il file scaricato dal portale.
  3. Se la licenza è valida viene salvata nell'app. Il file importato può essere eliminato automaticamente; se serve, si può scaricare di nuovo dal portale.
  1. Open ? → Activate PRO version or click the FREE badge.
  2. Choose Import licence file and select the file downloaded from the portal.
  3. If the licence is valid, it is saved in the app. The imported file may be deleted automatically; if needed, it can be downloaded again from the portal.
Si può incollare una chiave invece di importare il file?Can I paste a key instead of importing the file?
Sì. Nella finestra Activate PRO version apri l'opzione per inserire la chiave, incolla il testo ricevuto e scegli Activate. Il metodo consigliato resta l'importazione del file .ptvlic.Yes. In the Activate PRO version window open the key-entry option, paste the text you received and choose Activate. Importing the .ptvlic file remains the recommended method.
Cosa fare se l'attivazione mostra un errore?What should I do if activation shows an error?
  • This licence belongs to another machine. Controlla che il codice macchina sia quello di questo PC e richiedi dal portale una licenza per quel codice.
  • The licence is not valid for this machine. Verifica di aver ricevuto il file per il codice macchina corretto; se il messaggio resta, contatta il fornitore tramite il portale.
  • The licence expired on … Controlla la data indicata e invia una nuova richiesta dal portale.
  • The … recording hours of this licence are used up … Le ore di registrazione sono esaurite; contatta il fornitore tramite il portale.
  • Licence … has been withdrawn. Le funzioni PRO sono disattivate; chiedi informazioni al fornitore tramite il portale.
  • The date on this PC (…) is earlier than the date this licence was issued (…). Imposta la data corretta e riavvia l'app; non è un blocco permanente. Se invece compare Licence … was locked on this PC because the clock was set back., correggi la data e richiedi tramite il portale una nuova licenza per lo stesso codice macchina: reinstallare non sblocca la licenza.
  • This licence belongs to another machine. Check that the Machine Code is the one of this PC and request a licence for that code from the portal.
  • The licence is not valid for this machine. Check that you received the file for the correct Machine Code; if the message remains, contact the supplier through the portal.
  • The licence expired on … Check the date shown and send a new request from the portal.
  • The … recording hours of this licence are used up … The recording hours are used up; contact the supplier through the portal.
  • Licence … has been withdrawn. PRO features are disabled; ask the supplier for information through the portal.
  • The date on this PC (…) is earlier than the date this licence was issued (…). Set the correct date and restart the app; this is not a permanent lock. If instead the message is Licence … was locked on this PC because the clock was set back., correct the date and request a new licence for the same Machine Code through the portal: reinstalling does not unlock the licence.

D. UsoD. Use

Quali tipi di licenza esistono?Which types of licence are there?
A seconda del file emesso, una licenza può essere senza scadenza o con una data di scadenza, e può includere un numero di ore di registrazione e un limite ai tag Live. Il portale mostra la scadenza e i limiti assegnati. Prezzi e condizioni commerciali non sono indicati qui.Depending on the file issued, a licence can be perpetual or have an expiry date, and it can include a number of recording hours and a limit on Live tags. The portal shows the expiry and the limits assigned. Prices and commercial terms are not given here.
Cosa succede quando la licenza scade o le ore finiscono?What happens when the licence expires or the hours run out?
Le funzioni PRO si disattivano. Se una registrazione è in corso non viene interrotta: il file viene chiuso completo e le funzioni PRO si disattivano quando fermi la registrazione. Se raggiungi il limite dei tag Live, per aggiungerne un altro devi prima rimuoverne uno.PRO features are disabled. A recording in progress is not interrupted: the file is closed complete and PRO features are disabled when you stop the recording. If you reach the Live-tag limit, you must remove a tag before adding another.
Se aggiorno l'app, la licenza resta valida?Does my licence stay valid when I update the app?
Sì: un aggiornamento sullo stesso PC non cambia il codice macchina. Fanno eccezione le licenze emesse per le versioni precedenti alla 2.1, che questa versione non accetta: in quel caso copia il codice macchina e chiedi al fornitore una licenza sostitutiva tramite il portale.Yes: an update on the same PC does not change the Machine Code. The exception is licences issued for versions before 2.1, which this version does not accept: in that case copy the Machine Code and ask the supplier for a replacement licence through the portal.
Cosa succede se reinstallo Windows o cambio PC?What happens if I reinstall Windows or change PC?
Il codice macchina può cambiare e la licenza resta legata al codice del PC precedente. Invia una nuova richiesta dal portale con il nuovo codice e chiedi il trasferimento: la licenza precedente viene disattivata quando il trasferimento è completato. Sostituire un disco o aggiungere memoria non cambia il codice macchina. In una macchina virtuale il codice cambia anche quando la macchina virtuale viene copiata oppure spostata su un PC con un processore diverso.The Machine Code can change and the licence stays bound to the previous PC's code. Send a new request from the portal with the new code and ask for a transfer: the previous licence is disabled when the transfer is completed. Replacing a disk or adding memory does not change the Machine Code. In a virtual machine the code also changes when the virtual machine is copied, or moved to a PC with a different processor.
Il PC si è guastato o ho perso il file della licenza: cosa faccio?The PC failed or I lost the licence file: what do I do?
Se hai perso il file, controlla lo stato della richiesta sul portale: una licenza attiva si può scaricare di nuovo. Se il PC non è più utilizzabile o il codice macchina è cambiato, contatta il fornitore tramite il portale indicando il seriale e, se disponibile, il nuovo codice: verrà valutata una nuova emissione o un trasferimento.If you lost the file, check the request status on the portal: an active licence can be downloaded again. If the PC can no longer be used or the Machine Code has changed, contact the supplier through the portal with the serial and, if available, the new code: a reissue or a transfer will be considered.

E. Data e oraE. Date and time

Si può riportare indietro l'orologio del PC?Can I set the PC clock back?
No. Riportare indietro l'orologio può bloccare in modo permanente una licenza con scadenza su quel PC. Se è successo, correggi la data e richiedi tramite il portale una nuova licenza per lo stesso codice macchina; reinstallare l'app non elimina il blocco. Le licenze senza scadenza non controllano la data.No. Setting the clock back can permanently lock a licence with an expiry date on that PC. If it happened, correct the date and request a new licence for the same Machine Code through the portal; reinstalling the app does not remove the lock. Perpetual licences do not check the date.
Il cambio di fuso orario o dell'ora legale può bloccare la licenza?Can a change of time zone or daylight-saving time lock the licence?
No. Cambiare fuso orario o passare all'ora legale non equivale a riportare indietro la data. Non modificare la data a mano per simulare un altro fuso orario.No. Changing the time zone or switching to daylight-saving time is not the same as setting the date back. Do not change the date by hand to simulate another time zone.
La batteria del BIOS scarica ha impostato una data precedente: cosa faccio?A flat BIOS battery set an earlier date: what do I do?
Imposta data e ora corrette in Windows. Una data precedente al giorno di emissione della licenza va corretta, ma da sola non causa il blocco permanente descritto sopra. Una licenza importata da poco non viene bloccata per una data errata precedente all'importazione.Set the correct date and time in Windows. A date earlier than the licence issue date must be corrected, but on its own it does not cause the permanent lock described above. A recently imported licence is not locked because of a wrong date earlier than the import.

F. Revoca e trasferimentoF. Withdrawal and transfer

Cosa succede se una licenza viene revocata?What happens if a licence is withdrawn?
L'app passa alla versione Free, disattiva le funzioni PRO e mostra un avviso. Per conoscere il motivo o richiedere una nuova licenza contatta il fornitore tramite il portale. In caso di trasferimento a un altro PC, la licenza precedente viene sostituita.The app switches to the Free version, disables PRO features and shows a message. To find out why or request a new licence, contact the supplier through the portal. When a licence is transferred to another PC, the previous one is replaced.
Il PC non è collegato a internet: la licenza smette di funzionare?The PC is not connected to the internet: does the licence stop working?
No. Senza rete l'attivazione e l'uso funzionano normalmente. Un PC non collegato non riceve gli aggiornamenti sullo stato della licenza: una revoca viene applicata quando il PC torna in rete o quando si installa una versione successiva dell'app. Non vengono trasmessi dati del PLC.No. Without a network, activation and use work normally. A PC that is not connected does not receive licence status updates: a withdrawal is applied when the PC is back online or when a later version of the app is installed. No PLC data is transmitted.

G. InstallazioneG. Installation

Windows SmartScreen mostra un avviso: cosa faccio?Windows SmartScreen shows a warning: what do I do?
Verifica prima che il file provenga dalla pagina ufficiale delle release. Per continuare l'installazione scegli Ulteriori informazioni → Esegui comunque.First check that the file comes from the official releases page. To continue the installation, choose More info → Run anyway.
L'installazione è per utente? Serve installare .NET?Is the installation per user? Do I need to install .NET?
Sì, l'installazione è per utente e include il runtime dell'app: non serve installare .NET a parte. Per aggiornare, chiudi PlcTraceViewer e avvia l'installazione sopra la versione esistente.Yes, the installation is per user and includes the app runtime: .NET does not need to be installed separately. To update, close PlcTraceViewer and run the installer over the existing version.
Cos'è il servizio web e quando serve?What is the web service and when is it needed?
È il componente facoltativo che pubblica la dashboard Live nel browser sulla rete locale, per impostazione predefinita sulla porta 8085. La dashboard è una funzione PRO e non ha autenticazione: usala solo su una rete protetta. L'installazione del servizio richiede l'autorizzazione di Windows; se la dashboard non ti serve, non selezionare il componente durante l'installazione.It is the optional component that publishes the Live dashboard in the browser on the local network, on port 8085 by default. The dashboard is a PRO feature and has no authentication: use it only on a protected network. Installing the service requires Windows permission; if you do not need the dashboard, leave the component unselected during installation.
Come si disinstallano il programma e il servizio?How do I uninstall the program and the service?
Usa la voce di disinstallazione di PlcTraceViewer nel menu Start oppure Impostazioni di Windows → App installate. La procedura ferma e rimuove il servizio web prima di eliminare i file; Windows può chiedere l'autorizzazione.Use the PlcTraceViewer uninstall entry in the Start menu or Windows Settings → Installed apps. The procedure stops and removes the web service before deleting the files; Windows may ask for permission.
L'antivirus blocca l'app o la connessione: cosa faccio?My antivirus blocks the app or the connection: what do I do?
Verifica che il file di installazione provenga dalla pagina ufficiale delle release e segui la procedura IT della tua azienda per esaminare l'avviso. Se il blocco riguarda la dashboard web, controlla anche il servizio e la porta 8085.Check that the installer comes from the official releases page and follow your company's IT procedure to review the alert. If the block concerns the web dashboard, also check the service and port 8085.

I. SupportoI. Support

Quando contattare il supporto e quali informazioni inviare?When should I contact support and what should I send?
Contatta il supporto se il portale non trova una richiesta, se l'attivazione non riesce anche dopo aver verificato il codice macchina o se compare un errore non spiegato qui. Per la licenza scrivi tramite il portale licenze indicando seriale, codice macchina, versione di PlcTraceViewer e testo esatto del messaggio. Per un problema tecnico usa Segnala un problema indicando versione e messaggio, senza seriale né codice macchina. Non allegare registrazioni o dati d'impianto a una segnalazione pubblica.Contact support if the portal cannot find a request, if activation still fails after checking the Machine Code or if an error appears that is not explained here. For licence questions, write through the licence portal with the serial, Machine Code, PlcTraceViewer version and the exact text of the message. For a technical problem use Report an issue with the version and the message, without the serial or Machine Code. Do not attach recordings or plant data to a public report.
